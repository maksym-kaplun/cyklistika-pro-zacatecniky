# Cyklistika pro začátečníky

Jednostránkový mobile-first web o cyklistice pro začátečníky. Školní projekt (WEB, kapitoly 7–9).

## Klíčová slova
- cyklistika pro začátečníky
- první kolo
- výbava cyklisty
- bezpečná jízda na kole

## Použité technologie
- HTML5 (sémantické značky)
- CSS3 (Flexbox, Grid, media query)
